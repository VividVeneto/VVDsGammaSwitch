# GammaSwitch

Windows 10 SDR 下使用的 ICC / VCGT 快捷切换工具。中文界面，支持多显示器、自定义全局快捷键、多屏场景和原始状态恢复。

## 直接使用

运行 `dist/GammaSwitch/GammaSwitch.exe`。发行版自带 .NET 运行时，无需安装开发环境，无需管理员权限。

1. 首次启动会发现当前在线显示器，并为主屏建立现有的 `P27UEA.icm`、`tarkov.icc`、`tarkov_brighter.icc` 动作；首次启动没有任何快捷键绑定，也不会应用 ICC 或曲线。
2. 选择动作，点击 **编辑 / 快捷键**（或双击动作）。点击快捷键框，直接按下需要的组合键，然后点击 **保存并生效**。
3. 支持 Ctrl / Alt / Shift / Win 组合和独立功能键。普通字母、数字等需要搭配修饰键，F12 是系统保留键。系统保留组合或已被其他程序占用的键会提示注册失败；旧绑定会保留。点击 **清除** 或按 Delete 可以移除绑定。
4. 选择目标显示器和 ICC 文件。需要多屏一起切换时，使用 **应用预设 / 多屏场景** 类型，每台显示器添加一行；每行可选择不同文件和模式。
5. 首次应用前，请确认当前画面是你希望恢复到的日常状态。首次修改前会保存对应屏幕的原始 ICC、活动用户设置开关与完整伽马表。

关闭窗口后继续驻留托盘（第一次关闭时会弹出提示）。单击托盘图标打开设置；右键可以执行动作、暂停快捷键、恢复全部并退出。最近执行的动作会在托盘菜单中打勾，托盘提示显示“当前：动作名”；快捷键暂停时托盘图标变灰。默认在退出时恢复原始设置，可取消勾选。强制结束进程或断电无法保证即时恢复，下次启动会提示恢复。

### 界面速览

- **显示器**：列出在线屏幕、当前 ICC 和状态（未修改 / 已修改 · 可恢复 / 复制模式 / 读取失败）。选中一行，右侧显示该屏当前的伽马表；**恢复所选屏幕** 只恢复这一台。
- **动作与快捷键**：每行显示启用状态、动作类型、按键帽样式的快捷键和目标。最近执行的动作会标出“HH:mm 已应用”。右键动作可打开完整菜单。
- 右上角的 **快捷键运行中 / 已暂停** 标签可一键暂停或恢复全部全局快捷键，例如打字时避免误触。
- 底部状态栏带时间戳，并显示还有几台屏幕待恢复。

### 编辑动作

- 快捷键框下方会实时提示：可用、需要搭配修饰键、与其他已启用动作冲突等。
- 目标表格中点击单元格即可修改，下拉框会自动展开；**浏览…** 选择文件，也可以把 .icc / .icm 直接拖进表格。
- **文件检查** 列在保存前标出：含 VCGT / 无 VCGT / 找不到文件 / 无法读取 / 未安装（文件尚未安装到系统颜色目录，应用 ICC 时会失败）。右侧预览当前行 ICC 内的 VCGT 曲线。
- 保存失败时，错误显示在窗口底部，并指出是第几行，不会再弹窗打断。

### 键盘操作

| 位置 | 按键 | 作用 |
| --- | --- | --- |
| 动作列表 | Enter | 立即应用所选动作 |
| 动作列表 | F2 / 双击 | 编辑动作与快捷键 |
| 动作列表 | Delete | 删除（会确认） |
| 动作列表 | Ctrl+↑ / Ctrl+↓ | 调整顺序（托盘菜单同步） |
| 主窗口 | Ctrl+N / Ctrl+D / F5 | 添加动作 / 复制所选动作 / 刷新显示器 |
| 编辑窗口 | Ctrl+S / Esc | 保存并生效 / 取消 |
| 快捷键框 | Delete 或 Backspace / Esc | 清除绑定 / 离开输入框 |

## 三种应用模式

| 模式 | 行为 |
| --- | --- |
| ICC + 曲线 | 切换默认 ICC，并加载该文件的 VCGT；文件不含 VCGT 时，恢复首次修改前保存的曲线 |
| 仅曲线 | 保留默认 ICC，只加载文件中的 VCGT；没有 VCGT 时拒绝应用 |
| 仅 ICC | 切换默认 ICC，本程序不主动写入伽马表；Windows 或其他校准加载器仍可能响应 ICC 变化 |

VCGT 支持 1/3 通道、8/16 位表格数据，线性插值为 RGB 各 256 点；保留三个通道的独立数值。当前不支持公式型 VCGT，导入时会明确提示。对文件大小、目录范围、标签长度和曲线单调性做检查。

“日常 · P27UEA”采用 ICC + 曲线模式：因为该文件没有 VCGT，它使用保存的日常基准。每次从文件或基准直接加载，不对上一次曲线累计处理。

## 多显示器与循环

- 按显示器设备接口路径绑定，编号变化不会直接导致套用到另一台身份不同的屏幕；更换接口或系统重建设备身份后，需在编辑器重新选择。
- 仅支持可独立寻址的扩展桌面；检测到镜像 / 复制模式时拒绝独立切换。
- 循环动作的每一行必须指向同一台显示器，按行顺序轮换；可以用“上移 / 下移”调整顺序。
- 单屏恢复只恢复该屏；恢复全部会依次恢复本程序记录的屏幕。离线屏幕的恢复记录保留，重新连接后可重试。
- 多屏切换不是操作系统级的原子操作。程序会先检查全部目标与文件，保存恢复数据，再依次写入；中途失败会尝试回滚所有已触及的屏幕，并报告未能恢复的项目。

## 文件、安装与恢复

配置保存在 `%LOCALAPPDATA%/GammaSwitch/`：

| 文件 | 内容 |
| --- | --- |
| settings.json | 动作、显示器绑定、自定义快捷键和退出选项 |
| recovery.json | 尚待恢复的原始显示状态；操作前原子写入，恢复成功后移除对应条目 |
| activity.log | 操作结果及错误；大小超过 2 MB 后轮换 |

ICC + 曲线 / 仅 ICC 模式需要文件已经安装到 Windows 颜色目录。可先通过 Windows 颜色管理添加；仅曲线模式可以读取其他目录中的 ICC。程序不会自动提权安装文件。

恢复的是**活动默认 ICC、原来的用户设置开关和伽马表**。切换过程中加入的 ICC 关联列表条目可能保留，不会删除已安装的 ICC 或重建整个关联列表。

如果 settings.json 损坏，程序进入恢复模式并保留原文件，仍可恢复已有记录；修复该文件后重启。如果 recovery.json 损坏，程序停止启动以避免覆盖恢复数据，请保留原文件排查。

首次修改前捕获的基准会保留至成功恢复；不要在已有恢复记录时将游戏画面误当成新的日常基准。程序没有开机自启和强制反复写入曲线。

## 塔科夫兼容范围

这是独立桌面工具，使用 Windows 色彩管理、全局热键与 GDI 伽马表接口，不注入游戏进程。

目标环境是 Windows 10、HDR 关闭。驱动、游戏、其他色彩工具以及显示模式变化可能覆盖曲线。写入后会回读核对，允许最多 512/65535 的驱动量化差异；回读成功仍不能证明最终游戏画面一定采用该曲线。需要你分别测试无边框 / 独占全屏下的实际效果。切回桌面或改变显示模式后，可以再次执行同一动作。

程序不持续监控并抢写伽马表。避免同时让多个校准工具争用相同显示器。

## 开发、验证与打包

开发环境：Windows x64、.NET 10 SDK。项目没有外部 NuGet 业务依赖。

```powershell
# 核心行为测试；不访问真实显示设置
.\test.ps1

# 加上原生接口 / 真实窗口测试；不切换 ICC 或写入曲线
.\test.ps1 -Native

# 显式执行真实 ICC 往返与原曲线写回测试，结束时恢复原状态
# 测试前将当前屏幕状态备份到 artifacts/native-test-recovery.json
.\test.ps1 -NativeWrites

# 生成自带运行时的 x64 单文件程序
.\publish.ps1
```

只读诊断，不修改设置：

```powershell
.\dist\GammaSwitch\GammaSwitch.exe --diagnose "$PWD\diagnostics.json"
```

指定独立配置目录（排查或测试使用）：

```powershell
.\dist\GammaSwitch\GammaSwitch.exe --data-dir "$PWD\local-data"
```

核心代码位于 `src/GammaSwitch.Core`，Windows 接口和界面位于 `src/GammaSwitch`；控制台行为测试与原生测试分别位于 `tests/GammaSwitch.Tests` 和 `tests/GammaSwitch.NativeTests`。
